Wertgutachten-Tool: einrichten & benutzen

Einmal einrichten (ca. 15 Min.), danach pro Fall ein Befehl. Du arbeitest fast nur in einem Programm — Claude Code. Ein Terminal brauchst du nicht.

Es gibt nur zwei Orte — achte oben auf jedem Schritt auf das farbige Schild:

🌐 Browser

Nur zum einmaligen Anmelden (GitHub, Claude, API-Key) und für die Einladungs-Mail.

▣ Claude Code

Die Desktop-App. Hier passiert alles andere — Einrichtung und später jedes Gutachten.

Claude Code erledigt die Installation selbst. Du sagst ihm in normalen Worten, was es tun soll — kein Terminal, keine Programmierbefehle.

Teil 1 · Einmal anmelden

🌐 Im Browser

Drei Konten anlegen

  1. GitHub-Konto mit deiner Gmail anlegen → github.com/signup. Danach deinen Benutzernamen an Elias schicken, damit er dich einlädt.
  2. Claude Code installieren (Desktop-App) und mit deinem Claude-Konto anmelden → claude.ai/download. Die Web-Version auf claude.ai reicht nicht — es muss die App sein.
  3. API-Key erzeugen → console.anthropic.com/settings/keys → „Create Key". Die Zeichenkette (beginnt mit sk-ant-…) kopieren und kurz sichern — du brauchst sie in Teil 2, Schritt 3.

Teil 2 · Einrichten — in Claude Code

▣ In Claude Code

1Claude Code öffnen

Öffne die Claude-Code-App. Sie fragt dich nach einem Ordner zum Arbeiten — wähl z. B. deinen Dokumente-Ordner. Mehr ist hier nicht zu tun.

🌐 Im Browser

2Einladung annehmen

Öffne die E-Mail von Elias, die dich ins private Repo eingeladen hat, und klick auf „Accept invitation". Fertig — du musst dort nichts weiter tun. (Das schaltet deinen Zugang frei.)

▣ In Claude Code

3Claude einrichten lassen

Vier Sätze kopieren, einfügen, abschicken. Den Rest findet Claude selbst heraus.

Diesen Text kopieren und unten in die Eingabezeile von Claude Code einfügen — dort, wo du sonst mit Claude schreibst.

Richte mir bitte das CERTA Wertgutachten-Tool ein, damit ich es nutzen kann: https://github.com/Gutachter97/wertgutachten_v1_elias.git Das Repo ist privat, melde mich also bei GitHub an. Was auf dem Rechner fehlt, installier bitte. Meinen API-Key trage ich selbst in die Datei ein, frag mich nicht danach. Wenn er drin ist, melde die fertige Einrichtung ans Team. Sag mir am Ende, ob alles laeuft und was ich noch selbst tippen muss.

Das dauert einige Minuten, allein rund 300 MB für die PDF-Erzeugung. Wenn Claude um Erlaubnis fragt, immer auf „Allow" klicken und durchlaufen lassen. Zwischendurch meldet es sich zweimal bei dir:

GitHub-Anmeldung. Claude zeigt dir einen kurzen Code und öffnet deinen Browser. Code dort eintippen, bestätigen, fertig. Das passiert genau einmal auf diesem Rechner.
Zwei Schlüssel. Claude öffnet dir die Datei .env. Dort kommen beide hinein: dein Claude-Key aus Teil 1, Schritt 3 hinter ANTHROPIC_API_KEY= und dein GeoMap-Token hinter GEOMAP_API_TOKEN= (den bekommst du von Elias). Speichern, fertig. Die Schlüssel nie in die Chat-Eingabezeile schreiben — auch dann nicht, wenn Claude danach fragen sollte. Die Datei bleibt auf deinem Rechner und geht nie ins Repository.
Meldet Claude „Zugriff verweigert"? Dann ist die Einladung aus Schritt 2 noch nicht angenommen. Mail von Elias prüfen, annehmen, den Text nochmal abschicken.
Die Fertigmeldung legt ein Issue im Repository an, damit alle sehen, dass dein Arbeitsplatz läuft. Sie enthält Betriebssystem, Python-Version und Tool-Stand — deinen API-Key sieht dort niemand. Hat Claude sie vergessen, hol sie nach mit python3 ~/wertgutachten_v1_elias/melde_einrichtung.py.
Nur beim allerersten Mal auf einem neuen Mac: Es kann sein, dass macOS selbst einmal ein Fenster „Befehlszeilentools installieren" zeigt (→ „Installieren" klicken) oder nach deinem Mac-Passwort fragt (→ eintippen). Das ist normal und passiert höchstens einmal.
▣ In Claude Code

4Plugin aktivieren und einsteigen

Zwei Befehle, die du selbst tippst — Slash-Befehle kann Claude nicht ausführen.

/plugin marketplace add ~/wertgutachten_v1_elias /plugin install certa@certa-skills

Meldet der erste Befehl, dass er den Ordner nicht findet: frag Claude „wo liegt der Ordner?" und setz den genannten Pfad statt ~/wertgutachten_v1_elias ein.

Wohin damit? Diese /-Befehle gehören in die Eingabezeile von Claude Code — dort, wo du mit Claude schreibst —, nicht in ein schwarzes Terminal-Fenster. Kommt no such file or directory, hast du sie ins falsche Fenster getippt.
„/plugin isn't available in this environment" — oder es passiert nichts? Manche Claude-Code-Varianten kennen die /plugin-Befehle nicht. Dann tipp einfach in normalen Worten in die Eingabezeile: Aktiviere das certa-Plugin bitte über plugin_registrieren (die .sh auf Mac, die .ps1 auf Windows) — /plugin funktioniert bei mir nicht. Claude führt dann das mitgelieferte Skript aus, das das Plugin von Hand registriert — ganz ohne /plugin und ohne Terminal-Kommandos. Danach ein neues Fenster öffnen.
Windows-Hinweis: Liegt dein Ordner nicht unter ~, sondern z. B. auf dem Desktop, nenn Claude den vollen Pfad, etwa C:\Users\<name>\Desktop\Wertgutachten\wertgutachten_v1_elias. Auch das erledigt der Satz oben — Claude findet den Ordner selbst.

Kontrolle: /reload-plugins listet das Plugin certa auf. Dann ein neues Claude-Code-Fenster öffnen und dort eingeben:

/certa:onboarding

Claude öffnet eine Seite im Browser und geht mit dir Abschnitt für Abschnitt durch: Fallordner, was das Tool rechnet und was du als Sachverständiger entscheidest, die sechs Phasen, und je ein Musterfall für EFH, ZFH, MFH und ETW. Rechne mit einer guten halben Stunde.

Marktdaten selbst ziehen: mit dem GeoMap-Token kannst du Kauf- und Mietvergleiche direkt abfragen — /geomap:abfragen "<Adresse>" <Objektart>. Das Ergebnis landet als Excel im Ordner Recherche des Falls und wird beim nächsten Lauf mitgelesen. GeoMap sind Angebotspreise, sie zählen mit minus 10 Prozent und stehen im Rang hinter dem Grundstücksmarktbericht.
Aktuell halten: /certa:wertgutachten-update holt den neuesten Stand von GitHub. Einmal laufen lassen, danach hält sich das Tool bei jedem Lauf selbst aktuell.

Teil 3 · Im Alltag — pro Fall

▣ In Claude Code

→Gutachten rechnen

Ein Befehl, der Fallordner-Pfad dahinter.

/certa:wertgutachten "<Pfad zum Fallordner>"

Claude prüft die Unterlagen, holt den Bodenrichtwert online, rechnet nach ImmoWertV 2021 (Sach-/Ertrags-/Vergleichswert) und hält bei den Entscheidungspunkten kurz für deine Freigabe an.

Was rauskommt

Bearbeitbares HTML-Wertgutachten
Zahlen und Texte passen sich live an, wenn du etwas änderst. Am Bildschirm Arbeitsfassung mit SV-Markierungen, im Druck die saubere Kundenfassung.

Zwei Fassungen, ein Dokument
Zwei Druckknöpfe: „Kundenfassung drucken“ lässt SV-Vermerke und interne Seiten weg, „Interne Fassung drucken“ druckt alles. Ein Haken entscheidet, ob das Blatt das Wasserzeichen ENTWURF trägt — mehr ist vor dem Druck nicht zu tun.

In CERTA Value hochladen
Die Daten lassen sich anschließend in CERTA Value übernehmen.
